Sea Battle — морський бій по локальній мережі

Розставте флот. Знайдіть кораблі. Чат не потрібен.

Класичний морський бій для iPhone і iPad: проти комп’ютера, поруч по локальній мережі або онлайн через Game Center. Без реклами й без акаунта AviLab.

До AviLab

Три способи грати

Проти комп’ютера офлайн, хост або приєднання поруч по локальній мережі, або онлайн через Game Center — без акаунта AviLab і без ігрового чату.

Гра поруч по локальній мережі

Створіть або приєднайтеся до гри в одній локальній мережі. Трафік матчу лишається між пристроями. Для гри поруч інтернет не потрібен.

Онлайн через Game Center

Онлайн іде через Apple Game Center. Позивні — короткі мітки, не публічні профілі. Для гри поруч Game Center не потрібен.

Без зайвого шуму

Без чату, без реклами й без логіну AviLab. Розставте флот, ходіть по черзі й завершіть матч.

Приватність

Гра проти комп’ютера — офлайн. Гра поруч — лише локальна мережа. Онлайн обробляє Apple Game Center.

Часті запитання

Що таке Sea Battle?

Sea Battle — гра в морський бій для iPhone і iPad з режимами проти комп’ютера, поруч по локальній мережі та онлайн через Game Center.

Чи потрібен інтернет для гри поруч?

Ні. Хост і приєднання поруч використовують локальну мережу. Для цього режиму інтернет не потрібен.

Чи є чат у Sea Battle?

Ні. Ігрового чату й акаунта AviLab немає.

Чи потрібен Game Center для онлайну?

Так. Онлайн іде через Apple Game Center. Для гри поруч він не потрібен.

Які платформи підтримуються?

Sea Battle доступна для iPhone і iPad в App Store.
